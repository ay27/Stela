# Current website direction

Stela is an AI workbench for data analysis. Use the approved Chinese product
copy and matching English copy for SQL in Markdown, SQL in Chat, Stela Agent,
Canvas reports and data lineage, automatic knowledge maintenance, and connector
plugins. Emphasize continuity of analysis. Omit local-first and Pi promotion.

Use a single light palette. The hero has title and copy on the left and an
empty overview image slot on the right. Each of the six features has a full-width
row with copy restricted to the left column and an empty image slot on the right.
All seven slots use a subtle border and pale background at 1199:768, without
labels, icons, pictures or click behavior. Stack the columns below 820 px.

Keep language selection and repository links. Show Windows and Mac Apple Silicon
download buttons linking directly to fixed-name assets through GitHub latest/download. Omit getting-started and contributor sections.
Keep source images on disk for future use. This revision changes the website
only, without changing README, committing or publishing.

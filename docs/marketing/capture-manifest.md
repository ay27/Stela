# Website capture provenance

Real user-supplied Demo Vault captures, September 21–22, 2026.

The website uses 16 composed images under `docs/assets/screenshots`. Each includes an HTML/CSS heading and a proportional crop of a real capture. No SQL, data, or app text was repainted. Source filenames, SHA-256 hashes, crop bounds, and copy are recorded in `manifest.json`. Originals remain outside the repository.

- Markdown crops omit the private absolute-path toolbar.
- Chinese knowledge is the preloaded ecommerce-unit-economics Skill.
- English knowledge shows maintained ecommerce-marketing-spend-grain with source excerpts.
- Chinese Agent uses the analysis pane only, excluding the old broken bar chart.
- English Agent uses the workspace update capture: the separate agent capture contains an incorrect 60% spend statement and is not used.
- Chinese Chat uses chat3; the long chat capture labels USD as yuan and is not used.
- Lineage uses the expanded `lineage2` captures with actual amounts.

PNG files open at full size; WebP images provide 900px and 1800px variants.
